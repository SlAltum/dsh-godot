# Godot 界面插件

Godot 的界面功能以动态 Cordis 插件（dynamic Cordis plugin）形式提供。DSH 本体不包含任何 Godot 界面代码，需要时加载本插件即可。

> **设置卡片已迁移**：Godot 设置卡片现由持久客户端包 `ui-godot`（`@deepseek-ai/dsh-ui-godot`）提供——它是 `dsh.client` 行，能挺过 dsh web 进程重启。若部署组合已包含 `ui-godot`，本插件的设置卡注册会因同一 `godot` 键重复而被自身捕获降级（不影响工具卡），但建议在组合中只保留其一。迁移背景见 `ui-godot/README.md`。

## 功能

本插件向 Web 界面添加调试工具卡。

会话中出现 `godot_debug` 调用时，本插件把默认的通用工具卡替换为专属卡片。卡片内容包括：

- 摘要行：启动还是附加、目标场景或端口、断点数量；
- 停顿分区：每个停顿一个折叠区，含帧列表、变量、展开对象、编辑结果、场景树；
- 类图标：场景树与展开对象按引擎类名显示 Godot 官方图标（未命中类回退通用图标，颜色随主题自适应）。

调用失败时卡片标红，并自动展开报告。

**扩展图标类**：把类名对应的 SVG 放进 `godot-icons/` 目录后运行 `node gen-icons.mjs`，图标自动内联进插件文件，无需手写代码。

## 加载方式

两种方式任选其一。

**会话内临时加载**：请助手用 `cordis_define` 定义本插件（host 面取 `applyHost`，client 面取 `applyClient`），再用 `cordis_run` 激活。会话结束后插件自动消失。

**部署加载**：按部署环境的插件加载方式引入本文件（`ui-plugin-godot.js`）。

## 常见问题

**设置页面看不到 Godot 卡片。**
设置卡片依赖宿主安装 tool-godot 包（由它注册 `godot` 设置项）。确认宿主组合包含该包后，重新打开设置页面。

**卡片显示「此宿主未提供 godot 命名空间」。**
含义同上：当前宿主没有加载 Godot 工具包，卡片无法读写配置。

**调试报告为什么是英文？**
报告由调试工具直接生成，内容面向助手阅读，界面层不做翻译。
